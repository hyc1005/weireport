# 实验报告向导（lab-report-wizard）

在浏览器本地写实验报告：搭结构、填步骤、贴截图、自动保存，一键导出可继续编辑的 **.docx**。全程不联网、不上传。

专门为张伟老师的课程制作的实验报告生成向导，不确定相较于word的突出优势，欢迎大家尝试。

**在线体验**：<https://hyc1005.github.io/weireport/>
（与本地版同一份源码；数据只存在你当前浏览器的 IndexedDB 里，清站点数据会清空）

> 存储机制、分级序号、标题编号、封面预设、docx 生成原理、目录结构、已知边界，见 [**详细文档**](docs/DETAILED.md)。

## 安装

只需要做一次。先准备好环境，再把仓库拉到本地：

1. 安装 [Node.js](https://nodejs.org/)（18 以上，自带 `npm`），安装后命令行执行 `node -v` 能看到版本号即可
2. 浏览器用 **Chrome 或 Edge**（截图、读剪贴板需要安全上下文）
3. 克隆本仓库并进入目录：

```bash
git clone https://github.com/hyc1005/weireport.git
cd weireport
```

4. 安装依赖：

```bash
npm install
```

装完之后，日常使用只用「打开 / 关闭」两个脚本，不用重复执行本节。

> 不想装环境？可以直接用[**在线版**](https://hyc1005.github.io/weireport/)，功能一样，数据只存在你浏览器里。

## 打开 / 关闭（日常就用这两个）

| 做什么 | 双击 | 命令行 | 效果 |
|---|---|---|---|
| **打开** | `start.cmd` | `npm start` | 后台起服务，自动打开 `http://127.0.0.1:5273/` |
| **关闭** | `stop.cmd` | `npm run stop` | 结束服务进程树并释放 5273 端口 |

两个脚本都是幂等的：重复点「打开」不会起第二个服务，没运行时点「关闭」只会提示一句。也可以直接 `npm run dev` 前台跑，`stop.cmd` 照样能关掉它（按端口兜底）。

> ⚠️ 固定用 **`http://127.0.0.1:5273`** 访问。`localhost:5273` 与 `127.0.0.1:5273` 在浏览器眼里是**两个不同的源**，存储互不相通 —— 混着用会以为「数据没了」。截图（`getDisplayMedia`）和读剪贴板也需要安全上下文，所以请用 Chrome / Edge。

## 日常六步

1. **新建工程**：首页「＋ 新建工程」直接给一份课程报告骨架（封面 + 五节 + 空步骤），默认是「实验01」，在右侧「实验信息」里改序号、主题、学号、姓名即可。想复用旧报告的层级就用「从 Word 导入结构」（会先给逐行预览，确认后才建工程）。
2. **填封面**：选封面预设（课程报告 / 正式风 / 简洁风），填实验信息；顺手填个**截止日期**，工具栏就会出现 `剩 3 天 · 还差 5 项 → 每天 2 项` 的提醒，不填就不催。
3. **写内容**：纸面上方只有两个按钮 —— `＋ 插入 ▾`（文字 / 代码 / 图片 / 表格）和 `截取当前窗口`。剪贴板里不管是截图还是文字，焦点在纸面上按 `Ctrl+V` 就贴。删错了用 `Ctrl+Z` 撤回、`Ctrl+Shift+Z`（或 `Ctrl+Y`）重做。
4. **让序号自己长**：文字块下面有一个序号工具，`（1）` → `a)` → `①` → `1)` 四级，只有用过上一级才出现下一级；同一步骤里的多个文字块接着数（前一块写到 `（3）`，后一块直接从 `（4）` 起）。
5. **设置**：核对 Word 文件名规则、标题编号、页码与目录。存储、备份、导出 Markdown 这些低频项收在「设置 → 高级」，默认折叠。
6. **导出 Word**：会先弹一次确认，核对最终文件名，可选「给没图注的图自动补图 N」，然后用 Word / WPS 打开做最后微调。关页面不用手动保存。

## 不会丢数据的两个前提

- **固定用 `127.0.0.1:5273`**（见上）。
- **浏览器「清除站点数据」会连工程一起清掉**。重要报告定期留一份 JSON：整套备份在「设置 → 高级 → 导出全部工程（JSON 备份）」（连图片字节一起），单个工程在首页卡片「⋯ → 导出 JSON」，恢复用首页「导入 JSON 备份」。**导入不会盖掉本地那份**：同名工程会自动另存成「原名（备份导入）」。

## 开发与自检

```bash
npm run build    # tsc 类型检查 + vite 打包
npm run verify   # 离线自检五道闸门：存储 / 导出 / UI 渲染 / 标题编号对拍 / Word 导入，不需要浏览器
```

在线 demo 由 `main` 分支推送后自动构建部署（`.github/workflows/deploy.yml`）。
