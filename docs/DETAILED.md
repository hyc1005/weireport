# 实验报告向导（lab-report-wizard）

> 本文是**详细文档**：存储机制、分级序号、标题编号、封面预设、docx 生成原理、目录结构、已知边界。安装与日常使用见 [README](../README.md)。

按顺序填实验报告，随手截图/粘贴，一键导出 **.docx**。全程在浏览器本地完成，不联网、不上传。

## 启动 / 关闭（日常就用这两个）

| 做什么 | 双击 | 命令行 | 效果 |
|---|---|---|---|
| **打开本地网页** | `start.cmd` | `npm start` | 后台起服务，等端口通了自动打开浏览器。已在运行就直接开浏览器 |
| **关闭本地网页** | `stop.cmd` | `npm run stop` | 结束服务进程树并释放 5273 端口 |

两个脚本都是幂等的：重复点「打开」不会起第二个服务，没运行时点「关闭」只会提示一句。

首次使用要先装依赖：

```bash
npm install
```

脚本细节：`scripts/serve.ps1` / `scripts/stop.ps1`
- 服务日志写到 `devserver.out.log` / `devserver.err.log`（启动失败会把最后几行打出来）
- 进程号记在 `.devserver.pid`，关闭时按 pid 结束整棵进程树；找不到就兜底按端口找占用者
- 想不起浏览器、或换端口：`scripts\serve.ps1 -NoBrowser` / `-Port 6000`
- 直接敲 `npm run dev` 前台跑也可以，`stop.cmd` 同样能关掉它（按端口兜底）

> ⚠️ 必须用 **localhost / 127.0.0.1** 访问（截图 `getDisplayMedia`、读剪贴板 `clipboard.read` 都要求安全上下文），浏览器用 Chrome / Edge。

开发与自检：

```bash
npm run build      # tsc 类型检查 + vite 打包
npm run verify     # 离线自检五道闸门：存储 / 导出 / UI 渲染 / 标题编号对拍 / Word 导入，不需要浏览器
```

## 数据存在哪、怎么保证不丢

老版本把整份报告（含 base64 图片）塞进 localStorage，而 **localStorage 每个源只有约 5MB** —— 你两张地图截图 base64 后就有 6.3MB，写爆之后异常被静默吞掉，界面毫无提示，一刷新就回到上一次成功的版本。现在整套换掉了：

| | 之前 | 现在 |
|---|---|---|
| 存储 | localStorage，约 5MB | **IndexedDB**，通常可用到磁盘的百分之几十（几百 MB 起） |
| 图片 | base64 混在正文里，每次输入重写整份 | 按内容哈希**单独存二进制**（省掉 33% 膨胀），正文只剩几十 KB |
| 截图 | 原样入库（2~4MB/张） | 入库前压成 **WebP q0.9、单张 ≤400KB**（地图/代码截图缩小 8~15 倍） |
| 写失败 | 静默忽略 | **弹红条**，并提供「重试 / 导出 JSON 备份」 |

保存时机（三保险）：

1. 停手 700ms 存一次
2. **最长 3 秒强制存一次** —— 连续打字也不会一直不存
3. 切标签页 / 最小化 / 关页面 / `Ctrl+S` 立刻存

顶栏一直显示状态：`● 已保存 21:32` / `○ 保存中…` / `⚠ 保存失败`。关页面时如果最近 5 秒没成功保存过，浏览器会拦一下让你确认。

- **一次存完**：工程和它的列表索引在同一个 IndexedDB 事务里提交（`db.ts` 的 `write()`），删除、快照剪枝同理 —— 不存在「正文写好了、列表里查不到」的半截状态。保存失败会弹红条并拦住「回首页」，飞着的保存等它落地后再补一轮，最后几秒的编辑不会静默丢掉。
- **列表会自愈**：打开首页时如果发现某个工程在库里却不在索引里（老版本 meta 写失败留下的缺口），会按正文把它补回列表并重写索引，而不是当它不存在。
- **历史快照**：每个工程自动保留最近 3 版 JSON 快照，设置里可以随时「恢复」（恢复的老快照缺字段会先补默认值再入库）。完成 PDF 打印并确认保存后，可在设置 → 高级 里一次清理本工程的 3 份 JSON 快照。
- **图片回收**：每次保存后自动跑一次 GC，清掉没有任何工程/快照引用的图片；还被快照引用的要等那版快照被顶掉才回收，急着腾空间就点设置 → 高级 里的「清理未引用的图片」立刻清。要删的东西（快照、图片）都合并成**一个事务**提交，中途失败不会留下"删了一半"的列表。「这张图存过没有」也每次以库里的 key 为准（不缓存到内存），否则别的标签页回收过之后，同样的图会永远补不回字节。
- **老数据自动迁移**：首次打开会把 localStorage 里的工程搬进 IndexedDB，**全部写成功之后才删旧键**（搬不动就留着，宁可占着也不丢）。
- **整套备份带图片**：「设置 → 高级 → 导出全部工程（JSON 备份）」现在把图片字节一起内联进文件（`version: 2`）。以前只写 `assetIds` 引用，换个浏览器一导入图片全空 —— 引用离了这台设备的库就没有意义。首页「导入 JSON 备份」认得整套文件（也认老版没带 `assets` 的文件），一次把里面每个工程建回来；引用不到字节的图留空但文字照旧，提示里会报「N 张图片没能还原」。单工程「⋯ → 导出 JSON」一直是完整带图的（导出前会先把引用还原成 dataURL）。**导入不会盖掉本地那份**：备份里的工程和本地那份 id 相同（备份就是从它导出的），撞号时自动另存成「原名（备份导入）」并在提示里说明 —— 导入老备份不该把你眼前正在写的版本静默回滚掉。
- **容量看得见**：设置 → 高级，显示已用/可用额度、图片张数与占用。低频的「导出 Markdown」「导出全部工程」「恢复默认排版」「清空内容」也都收在这一栏，平时不打扰。

> ⚠️ 固定用 `http://127.0.0.1:5273`。`localhost:5273` 与 `127.0.0.1:5273` 在浏览器眼里是**两个不同的源**，存储互不相通 —— 混着用会以为"数据没了"。

- **首页就是工程列表**：顶部一排三个动作（新建工程 / 从 Word 导入结构 / 导入 JSON 备份），下面是卡片列表。卡片上只留「打开」和一个 `⋯`，重命名、复制一份、只抄结构新建、导出 JSON、删除都收在 `⋯` 里。老的「单草稿」数据会自动迁移成第一个工程。
- **从 Word 导入结构**：首页点「从 Word 导入结构」，选一份 `.docx`。工具按三层判级别（Word 标题样式 → `w:numPr` 自动编号 → 中文手写编号与排版启发式），先在**导入预览**里逐行给出「原文 / 作为 / 判定依据 / 把握」，**确认后才建工程**；把握不足 75% 的行黄底标出，每行都能改级别，也可以整份「按纯文本导入」兜底。疑似封面的信息行（学号 / 姓名 / 日期）默认跳过。表格整块进工程，不会散成正文；正文里的内嵌图片按原位置一起搬进来（入库前压成 WebP），预览的图片行带缩略图、只能选「正文 / 忽略」。EMF/WMF 这类浏览器解不了的格式、以及短边小于 48px 的装饰图会被跳过，预览里报「另有 N 张图片没能读出」。导入后可用 `⋯ → 只抄结构新建` 复用结构。
- **纸面上方只有两个按钮**：`＋ 插入 ▾`（文字 / 代码 / 图片 / 表格）和 `截取当前窗口`。剪贴板里不管是截图还是文字，焦点在纸面上按 `Ctrl+V` 就贴，不再单独摆两个按钮。贴上去的东西落在哪儿只有一套规则（`putText` / `putImage`）：选中的是文字/代码块就并进那块，选中图片块就是换图，选中别的块就插在它后面，没选中才追加到末尾 —— 「＋ 插入」新建空块和截图 / 剪贴板那三个入口用的是同一套位置规则，不会出现「明明选中了却贴到最后」。`p` / `c` / `t` 单键新建块用的是同一份位置算法（`reportOps.afterBlock`）：选中的块不在当前页时（切页后残留的选中态）一律追加到末尾，不会突然插到页首。弹窗开着时、焦点在下拉框里时这些单键都不抢。
- **Ctrl+Z 撤销 / Ctrl+Shift+Z（或 Ctrl+Y）重做**：文档级撤销，删块、插块、改标题、填封面信息、清空内容统统能撤回；同一个输入框 1.5 秒内的连续打字合并算一步，撤销栈保留最近 80 步。切工程 / 恢复快照时栈清空，不会把上一份工程的操作撤到现在。快照回滚（设置 → 高级）仍是跨会话的兜底。
- **导出前确认弹窗**：点「导出 Word」（含向导末页的「完成并导出」）必弹一次确认：只读展示按设置规则算好的**最终文件名**，外加一个勾选框「给没图注的图片自动补图 N」——全文按出现顺序连续编号（与纸面、Markdown 同一口径），手写过的图注不覆盖，纯空图块不占号；勾选**只影响这一次导出的文件**，不改工程数据。默认不勾，取消/✕/点遮罩都可直接关（生成中不可关）。
- **导出图片宽度夹进版心、比例保持**：超过版心的截图按版心宽输出，高从夹过的宽推算（1920×1080 在 Word 里仍是 16:9，不会被横向压扁）；`verify-export` 有防回退断言，已做变异测。
- **A4 纸面编辑**：纸面尺寸 794×1123px、内边距与 Word 页边距一致（上下 1 英寸、左右 0.75 英寸），字号行距直接用 pt 渲染 —— 所见即所得，居中/缩进/封面都能当场看到。
- **向导条常驻**：`第 n / N 步` + 进度线 + `← 上一步 / 下一步 →`，最后一页自动变成「完成并导出」，左侧状态点标出哪些页还空着。
- **截止日期反推每天写几项**：封面页右侧「实验信息 → 截止日期」选一天（不填就等于不设 deadline），纸面上方工具栏右端出现 `剩 3 天 · 还差 5 项 → 每天 2 项`，首页卡片上只标 `剩 3 天`。还剩 1~2 天变黄、到期当天或已逾期变红，填满后安静地说「内容已填满」。日期脏了（比如手填成 `2026-13-45`）就当没填，不显示也不催。
- **块属性**（鼠标移到块上出现）：文字块可设 左/中/右/两端 对齐 + 首行缩进；图片块可设对齐、宽度（原始/100/80/60/40%）、是否显示图注；代码块可切语言标签与底纹；表格块可切表头。块级设置只作用于这一块。
- **图标只用单色字形**：按钮里的彩色 emoji（🖥 🖼 📋）全部撤掉，只留 `＋ ⋯ ✕ ✎ ▾ ⬆ ⬇ ✓` 这类跟着字色走的符号；输入框的焦点光环改成主题色（原来是残留的蓝色），`＋ 插入` 和卡片 `⋯` 两个下拉现在能用 Esc 关。

## 分级序号（写步骤最常用的东西）

文字块下面有一个序号工具，**只插纯序号，不带任何后续文字**：

| 级别 | 字样 |
|---|---|
| 一级 | `（1）` `（2）` `（3）` … |
| 二级 | `a)` `b)` `c)` … `z)` `aa)` … |
| 三级 | `①` `②` `③` … |
| 四级 | `1)` `2)` `3)` … |

规则：

- **只有用过上一级，才会出现下一级的序号**：空文字块只有「一级」一行；插了 `（1）`，二级那一行才出现；二级用了才出三级，最多四级。
- **同级用到第几个，就多给出下一个**：插到 `（3）` 时列表里自动冒出 `（4）`；同级上限 49 个。
- **同一步骤里的多个文字块接着数**：前一个块写到 `（3）`，下一个块的工具条直接从 `（4）` 起 —— 序号看的是整步，不是单个输入框。
- **插在行首**：该行还没有序号 → 插到行首，光标停在原文末尾，接着打字就行；该行已有序号 → 在光标处另起一行，子级自动带一个全角缩进。
- **子级计数跟着父级走**：新起一个 `（2）`，它下面的子项又从 `a)` 开始。
- 带序号的行导出到 Word 时**不加首行缩进**（靠序号自己对齐），普通段落照旧缩进 2 字符。

另外文字块在纸面上是**按段落渲染**的（每行各自缩进/对齐，和 Word 一致），点一下才切成输入框。

## 标题编号：一个来源 + 三个设置

小节标题（`一、`）与步骤标题（`1.`）的编号**只由 `src/headings.ts` 的 `computeHeadings()` 算一次**，目录、纸面、打印预览、Markdown、导出 Word 五个渲染点只读它的结果 —— 不会出现「左边 1/2、里面 A/B」。

设置里可改（跟工程一起存，不改排版只改编号）：

| 设置 | 取值 | 说明 |
|---|---|---|
| 步骤编号字形 | 无 / `1.` / `（1）` / `A.` / `一、` / `I.` | 默认 `1.` |
| 步骤编号重计 | 全文连续 / 每节重新 | 默认**每节重新**（一、二、三 是手写在小节标题里的骨架，步骤号从每个小节的 1. 起；选「全文连续」时三的 1.2. 会接着数成四的 3.） |
| 小节编号字形 | 无 / `1.` / `（1）` / `A.` / `一、` / `I.` | 默认「无」，即沿用模板里的「一、二、三」写在小节标题文字里 |

两条配套规则：

- **不占号即不导出**：既没标题也没内容的步骤/小节不占序号，五个渲染点同时少一行，号也不会跳。
- **沿用作者编号**：标题里已经手写了编号（`1. 添加图层`）时系统编号让位，纸面上标灰色「沿用原编号」，但**该步仍占号**，所以删掉一行也不会前后错位。

`npm run verify:headings` 把这五个渲染点的编号序列抓出来逐字符对拍，字形 × 重计（两种范围都覆盖）× 手写编号 × 空节共 11 组组合，任何一处跑偏就红。

> **为什么会默认「每节重新」**：预设骨架的小节编号是手写在标题里的（`一、二、三`），如果步骤编号全文连续，「四、课堂任务」下的第一条就会接着「三、实验步骤」数成 `3.`，在**没有小节编号的目录里**看起来像挂到了上一节下面。设置里检测到「某个小节的第一条不是 1.」时会直接给一个「按小节重排编号」按钮，一键切到每节重新。

## 封面三种预设

| 预设 | 效果 |
|---|---|
| **课程报告**（新建默认） | 参考 dierci：独立大字封面、宽页边距、蓝绿标题，正文从第 2 页开始 |
| **正式风** | 独立封面页：特大标题居中 → 课程名 → 学号 / 姓名 / 日期 → 分页，正文从第 2 页开始 |
| **简洁风**（从 Word 导入时用） | 不单独占页，首行就是大标题，下面一行学号/姓名/日期 —— 和你原来那 7 份报告一模一样 |

> 2026-09-19 起「表格式」封面已下线（可增删行的信息表编辑器带来的复杂度不值当）；老工程里存过的 `cover.style === "table"` 载入时自动按**正式风**渲染，学号/姓名/课程/日期照常出现在封面页。真需要表格封面就在 Word 里最后微调，或从旧报告「从 Word 导入结构」。

封面页在纸面上实时预览。设置里还可以开 **页脚页码** 和 **自动目录页**（有真标题级别才能生成目录）。

**大标题在纸面上就地改**：右边面板的「标题」输入框仍然在，但更顺手的是直接点纸面上的大标题 —— 那行字本身就是输入框（三种封面风格都支持），点一下变虚线框原地编辑，`Enter` / 点别处保存，`Esc` 放弃。编辑态和排版结果用同一套字号、行高、居中方式，不换行、不跳动；留空则回到「实验N：主题」的自动标题。

**学号 / 姓名按这台机器记住**：这两个字段不是某个工程的属性，改一次就写进 localStorage（`lab-report-wizard:author`，键名与读写逻辑在 `src/template.ts`），新建工程自动带上，打开学号姓名为空的老工程 / 导入件时也会补上（**已经填过的绝不覆盖**）。只存在本机、只放两行字，不随工程导出、不上云；设置 → 高级里有「忘掉记住的学号姓名」可以反悔（只影响以后新建，不动已写进工程里的值）。

## 导出的 Word 是怎么生成的

**不再经过 Markdown / 第三方转换器**，而是直接由块模型生成 OOXML（`src/docx/build.ts`，用 `docx` 库，浏览器本地跑）：

| 层级 | Word 样式 | 字号 | 大纲级别 |
|---|---|---|---|
| 报告大标题 | Heading 1（黑体、居中/左） | 小二 18pt | 1 级 |
| 一、二、三 小节 | Heading 2（黑体） | 三号 16pt | 2 级 |
| 1. 2. 3. 步骤 | Heading 3（黑体） | 四号 14pt | 3 级 |
| 正文 | 宋体 + Times New Roman | 小四 12pt，1.5 倍行距，首行缩进 2 字符 | — |
| 代码 | Consolas + 宋体（中文注释不变方框），浅灰底纹 | 五号 10pt | — |

字号严格递减，且每个标题都带 **大纲级别**（`w:outlineLvl`）—— 这是 Word 导航窗格和「引用→目录」能认出 1 级/2 级标题的前提。

> 上一版之所以「看不出分级」，有两个原因：① 字号映射写错，大标题和小节都被设成 16pt；② 用的转换库根本不写大纲级别。现在两条都修了，`npm run verify` 里有断言守着。

图片按原始像素比例缩放（1px = 9525 EMU 写进 `wp:extent`），宽度可选百分比；表格列宽按正文宽度均分；代码块是一个带底纹的单格表格（不会跑版）。

图片尺寸这一处有下限和上限两道 clamp：宽度落在 1px ~ 正文宽之间，`w` / `h` / `widthPct` 只要是 0、负数、`NaN`、`Infinity` 这类脏值就逐项退回兜底尺寸（原始宽缺失按正文宽 80%、高度按比例兜），因为 `cx="0"` 或天文数字的宽度会被 Word 显示成坏图 —— 正常界面选不出这些值，会撞到的是老工程和历史导入件。

## 已知边界

- 截图拿的是「共享窗口的画面」，弹窗盖住窗口就截到被盖住的画面；要干净的图先让目标窗口在最前。
- 图片入库前会被压到单张 ≤400KB（WebP）；如果你需要投稿级画质，可在 `src/capture.ts` 把 `targetBytes` / `maxWidth` 调大。
- 导出 docx 时会把 WebP 转回 PNG/JPEG（Word 不认 WebP），所以原图会经历一次有损压缩；docx 里的图片不会再变模糊，但也不是原始像素。
- `getDisplayMedia` 必须由用户点击触发，做不了「定时自动截图」。
- 自动目录页需要 Word 打开时刷新一次域（已写入 `updateFields`，Word 会弹提示，点「是」即可）。
- 行内格式只支持 `**加粗**`、`*斜体*`、`` `行内代码` ``，不做完整 Markdown。
- 浏览器「清除站点数据」会连 IndexedDB 一起清掉，重要报告建议用「导出全部工程（JSON 备份）」留一份（这份备份现在带图片字节，文件会比工程本身大不少）。
- 导出 Word 时如果某张图片的字节读不出来（引用断了 / mime 不认识），**不会静默少内容**：那张图的位置保留图注，页面上弹一条警告点名是哪个步骤掉的图。
- Word 导入的级别判定是启发式的：没有样式也没有编号的纯加粗标题猜不准，所以一律先给预览、由你确认；把握不足 75% 的行会黄底标出，绝不会静悄悄下沉。
- **Word 导入带内嵌图片**：`.docx` 正文里的图片按原位置进工程（浏览器解不了的 EMF/WMF、小于 48px 的装饰图会跳过并在预览里报数），文本框 / 艺术字 / 公式仍不解析。
- Word 里的文本框、艺术字、公式等非标准段落会被跳过 —— 表格除外，表格按文档顺序整块保留。**格子里再套一层表**也保住了：外层表照常当一个表格块，内层表全部段落的文字按文档顺序拉平进它所在的那个格子（内层的表格线不还原），所以那份内容不会再凭空消失。要是哪份 Word 的嵌套表其实是真结构（比如分栏答题表），现在会变成一长条文字，需要在工程里手拆。
